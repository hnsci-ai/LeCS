# LeCS 1.6 — 网页版 CS 1.6 风格 3D 对战游戏

一个纯网页版的 3D 第一人称射击游戏，致敬 CS 1.6：dust2 风格地图、经典爆破模式（埋包/拆弹）、经济系统（买枪、护甲）、支持**多人联机对战**和**添加电脑玩家（Bot）**。

## 特性

- 🎮 **3D 仿真 CS 1.6**：Three.js 渲染，dust2 风格地图（A/B 点、长道、中路、隧道、双开门），第一人称视角，指针锁定瞄准
- 🌐 **多人对战**：Node.js + WebSocket 权威服务器，房间码邀请好友，最多 10 人（5v5）
- 🤖 **电脑玩家（Bot）**：寻路（A* 导航网格）、战斗 AI（视线检测/走位/压枪）、自动埋包/拆包，3 档难度，游戏中随时 F3 添加 / F4 移除
- 💣 **经典爆破模式**：C4 安放/拆除、45 秒爆炸计时、回合制、击杀奖励、连败补偿、护甲/头盔/拆弹器
- 💰 **经济与购买**：CS 1.6 风格买枪菜单（B 键），USP / Glock / 沙漠之鹰 / MP5 / AK-47 / M4A1 / AWP / 高爆手雷
- 🔫 **完整枪械手感**：弹道扩散、后坐力、爆头判定（4 倍伤害）、穿墙衰减、曳光弹、换弹动画
- 🖥 **HUD**：血量/护甲、弹药/金钱、雷达、击杀榜、购买菜单、记分板（Tab）、受击方向指示、埋包/拆包进度条
- 🔊 **合成音效**：WebAudio 程序化生成枪声、脚步、C4 滴滴声、爆炸，无需任何音频素材
- 🕸 **网络优化**：客户端预测 + 服务器和解、快照插值、延迟补偿（回溯命中判定）、30Hz 快照

另有**死斗模式**：无限复活、全武器免费。

## 快速开始

```bash
# 需要 Node.js 18+
npm install
npm start
```

打开浏览器访问 **http://localhost:8080**

- **单人对战电脑**：大厅选择电脑数量与难度 → 进入游戏
- **多人联机**：一人点「创建房间」，把屏幕左下角的 4 位房间码发给好友（同一局域网），好友输入房间码点「加入房间」
- 局域网其他电脑访问：`http://<本机IP>:8080`（服务器已监听 0.0.0.0）
- 如需公网联机，可将 8080 端口内网穿透（如 frp/ngrok）

## 操作

| 按键 | 功能 |
|------|------|
| WASD | 移动（Shift 静步、Ctrl 蹲、空格跳） |
| 鼠标 | 左键射击、右键刀刺、移动视角 |
| R | 换弹 |
| 1-5 | 切换武器（主枪/手枪/刀/手雷/C4） |
| B | 购买菜单（数字键或点击购买） |
| E | 安放 / 拆除 C4 |
| Tab | 记分板 |
| F3 / F4 | 添加 / 移除 Bot |

## 玩法规则（经典模式）

- 恐怖分子（T）携带 C4，需在 A/B 点安放并保护至爆炸；反恐精英（CT）需阻止或拆除 C4
- 回合制：冻结时间购买装备 → 战斗 → 结算金钱 → 下一回合
- 胜利奖金 +$3250，连败补偿递增；击杀 +$300，安放 C4 +$800，拆除 C4 +$300
- 死亡后本回合观战队友，下回合重生（死亡会失去武器，幸存保留）

## 技术架构

```
LeCS/
├── server/            # Node.js 权威服务器
│   ├── index.js       # HTTP 静态服务 + WebSocket + 房间管理
│   ├── game.js        # 游戏状态：物理、命中判定、伤害、经济、回合、C4
│   └── bots.js        # Bot AI：感知、A* 寻路、战斗、埋包/拆包
├── shared/            # 服务器/客户端共用（UMD）
│   ├── mapdata.js     # dust2 风格地图几何 + 导航网格 + 射线检测
│   ├── weapons.js     # 武器数值与购买菜单
│   ├── movement.js    # 移动物理（服务器权威 + 客户端预测同一实现）
│   └── constants.js   # 常量
└── public/            # 浏览器客户端（无构建，原生 JS + Three.js）
    ├── js/main.js     # 主循环：网络、预测/插值、事件
    ├── js/render.js   # Three.js 场景、地图、玩家模型、特效
    ├── js/viewmodel.js# 第一人称武器模型与动画
    ├── js/hud.js      # HUD、雷达、购买菜单、记分板
    ├── js/audio.js    # WebAudio 合成音效
    └── js/input.js    # 输入与指针锁定
```

协议：JSON over WebSocket。客户端 30Hz 发送输入（带序号），服务器 30Hz 广播快照（玩家状态/C4/手雷/枪声事件），客户端本地预测 + 快照和解，其他玩家 100ms 插值缓冲。
